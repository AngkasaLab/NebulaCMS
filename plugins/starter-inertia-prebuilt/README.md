# Starter Inertia Prebuilt

Official built-in starter plugin for NebulaCMS that demonstrates the pattern for prebuilt Inertia-based admin plugins.

## Purpose

This plugin is created as a reference for plugin authors who want to:
- add React/Inertia admin pages,
- maintain compatibility with shared hosting environments,
- distribute plugin ZIP files that include their own pre-built `dist/` directory.
